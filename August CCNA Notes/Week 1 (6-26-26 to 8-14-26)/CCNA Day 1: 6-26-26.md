Computer Network - A computer is a digital telecommunications network which allows nodes to share resources.

Node Examples - Router, Switch, Firewall, Server (referred to as endhost/endpoint), Client (referred to as endhost/endpoint). 

Network Example -> “Both Nodes are sharing resources as they are connected via a cable. And can communicate with each other. Clients can be a Laptop, PC, MAC, Iphone etc.

Switches - Used to forward traffic in a LAN (Local Area Network). Switches provide many network interfaces (ports) usually 24 or more ports. CANNOT provide connectivity between LANS / over the internet unless it is a LAYER 3 SWITCH 

Routers - Less network interfaces in switches (less ports). Routers are used to provide connectivity between LANs. Routers are used to send data over the internet. 

Firewalls - Help protect against malicious hackers based on specific rules. Firewalls are security devices designed to help protect and control network traffic entering and exiting the network. Firewalls can be placed externally (outside of the router) or internally (behind the router). NGFW (Next Generation Firewalls) have modern and advanced filtering. 

Network Firewalls - Hardware devices that filter traffic between networks. 

Host Based Firewall - Software applications that filter traffic entering an existing host machine (PC, laptop, phone, etc.)
